MB Channel Manager

A private desktop tool for managing my own YouTube channels.

MB Channel Manager is a desktop application used solely by its owner to manage YouTube channels that the owner operates. It uses the YouTube Data API to:

  • Upload videos and set their titles, descriptions, tags and thumbnails
  • Schedule videos to go live at set times
  • Add translated titles and descriptions (localizations)
  • Read basic channel and video information to keep production records up to date

The application is not offered to the public, is not sold, and does not access any channel or account other than those owned by the operator.
